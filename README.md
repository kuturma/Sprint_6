## **Тестовые сценарии**:
* 1 Переход на страницу по нажатию на логотип в шапке страницы
* 2 Сравнение что ответы в раскрывающемся списка соответствуют "Вопросам о важном"
* 3 Получение подтверждения, что заказ был создан (тестируется два пользователя)

Sprint_6_develop/
├── allure-report/                      # сгенерированный Allure-отчёт
    └── index.html                      # сгенерированный Allure-отчёт в html
├── curl/                               # URL
    └── curl.py                         # URL
├── helpers/                            # Помощниковые классы
    └── answers_text.py                 # Данные для сопоставления вопросов и ответов на главной странице
    └── data_for_order.py               # Данные для заполнения формы заказа самоката
├── locators/                           # Локаторы элементов страниц
    └── locators_main_page.py           # Локаторы с главной страницы
    └── locators_order_page.py          # Локаторы со страницы заказа самоката
├── pages/                              # Классы для работы с страницами
    └── main_page.py                    # Классы и методы для работы с главной страницей
    └── order_page.py                   # Классы и методы для работы со страницей заказа самоката
├── tests/                              # Тестовые файлы
    └── test_answer_and_question.py     # Тесты на сопоставление вопросов и ответов на главной странице
    └── test_check_enter_data_order.py  # Тесты на заполнение данных и успешного оформления заказа
    └── test_logo.py                    # Тесты переходов по нажатиям на логотипы в шапке сайта
├── .gitignore                          # Файлы, папки,  исключаемые из коммита
├── README.md                           # Документация
└── requirements.txt                    # Зависимости проекта


**Запуск всех тестов:**
```bash
python -m pytest tests/
```


**Запуск конкретного теста:**
```bash
python -m test_logo.py
```

**Открыть отчёт:**
```bash
allure open allure_report
```
